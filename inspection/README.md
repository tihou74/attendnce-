# مكان ملفّات تقرير التفتيش

ارفع هنا ملفّات بنود التفتيش — النسخة العربية والنسخة الإنجليزية.

## ما يُرفع

| الملفّ | ما هو |
|---|---|
| `inspection-ar.docx` | بنود التفتيش — النسخة العربية |
| `inspection-en.docx` | بنود التفتيش — النسخة الإنجليزية |
| `inspection.xlsx` | نسخة الإكسل، إن كانت البنود فيها مرتّبة |

**الأسماء ليست إلزامية** — ارفع الملفّ باسمه كما هو، فقط اجعله **بحروف إنجليزية**
(الأسماء العربية تتعطّل في الروابط على GitHub Pages).

## خطوات الرفع

1. اسحب الملفّ وأفلته في هذه الصفحة.
2. انزل إلى أسفل الصفحة.
3. اضغط الزرّ الأخضر **Commit changes** — ⚠️ **الرفع لا يكتمل بدونه.**

وإن نزل الملفّ في مكان آخر من المستودع فلا بأس: يُبحث عنه ويُنقل إلى هنا.

## ملاحظة

هذا المجلّد للمصادر المرجعية فقط. البنود تُقرأ منه مرّة واحدة وتُكتب داخل شاشة
التفتيش في `index.html`، فلا تُقرأ هذه الملفّات وقت التشغيل ولا يحتاجها المتصفّح.
